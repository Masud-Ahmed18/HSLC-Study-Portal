⚙️ Accuracy & ASSEB Pattern

Verification hierarchy

  1. Official ASSEB documents — highest authority.
  2. Recent actual HSLC papers — analyze section structure, marks, choices and question types.
  3. Prescribed textbooks/syllabus — content boundary.
  4. Reputable educational resources — supporting signals only (e.g. PW, Next Toppers and similar resources).
  5. AI-generated questions — original practice, clearly labelled as AI-generated.
Safety against hallucination: The system must not invent an ASSEB pattern. If current official evidence is unavailable, it should say “pattern not verified” rather than present a generic board format as current.
Copyright-aware research: External websites can be used to identify topics and trends, but the app should not copy their copyrighted question banks wholesale. Generate original practice questions and provide source attribution where appropriate.
