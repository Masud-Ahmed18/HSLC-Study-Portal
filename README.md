 Important 

The frontend deliberately does not claim an unverified current ASSEB question pattern. For production, connect:
1.latest official ASSEB syllabus/pattern documents,
2.verified HSLC papers,
3.a searchable source/retrieval layer,
4.Firebase/Supabase,
5.a server-side AI API.
External study websites may be used as supporting research sources, but copyrighted question banks should not be copied wholesale. Generate original practice questions and keep source attribution.
